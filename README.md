# Milo

Milo is a minimal, human-first social app prototype built with Expo, React Native, TypeScript, and Expo Router.

## Run locally

```bash
pnpm install
pnpm start
```

Then scan the QR code with Expo Go, or press `i`, `a`, or `w` for iOS, Android, or web.

## Checks

```bash
pnpm typecheck
pnpm check:deps
```

Sprint 1 is intentionally local-only: mock identity, conversations, discovery, profiles, messaging, AI suggestion UI, settings, and group creation are held in memory.
